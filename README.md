Unity classroom game-development project.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Demo 2.unity](https://github.com/kleberandrade/tirin-aulas-unity/blob/master/Assets/Scenes/Demo%202.unity), [Assets/Scenes/SampleScene.unity](https://github.com/kleberandrade/tirin-aulas-unity/blob/master/Assets/Scenes/SampleScene.unity), [Assets/Scenes/Tic Tac Toe.unity](https://github.com/kleberandrade/tirin-aulas-unity/blob/master/Assets/Scenes/Tic%20Tac%20Toe.unity), [Assets/_Packages/PandaBehaviour/Examples/00_ChangeColor/ChangeColor.unity](https://github.com/kleberandrade/tirin-aulas-unity/blob/master/Assets/_Packages/PandaBehaviour/Examples/00_ChangeColor/ChangeColor.unity), [Assets/_Packages/PandaBehaviour/Examples/01_Move/Move.unity](https://github.com/kleberandrade/tirin-aulas-unity/blob/master/Assets/_Packages/PandaBehaviour/Examples/01_Move/Move.unity).
